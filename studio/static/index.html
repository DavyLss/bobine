TEXTES ET MINIATURES SUR LE POSTE · DIFFUSION SUR VOS COMPTES

Connexions de publication

API directes pour YouTube et Instagram, Buffer pour TikTok. Les connexions sont propres à ce poste et ne sont pas enregistrées dans GitHub.

YouTube · API officielle

Non connecté

Notice : obtenir les accès YouTube
  1. Créer un projet dans Google Cloud Console et activer YouTube Data API v3.
  2. Configurer l’écran de consentement OAuth. Si l’application est en test, ajouter votre compte Google aux utilisateurs de test.
  3. Créer un client OAuth « Application Web » dans Identifiants, puis copier le Client ID et le secret ici. L’import JSON est aussi disponible.
  4. Déclarer exactement cette URL de redirection : Chargement….
  5. Enregistrer, puis « Connecter avec Google » et choisir le compte propriétaire de la chaîne. Les scopes demandés sont youtube.upload et youtube.readonly.

Pas d’abonnement de publication requis ; quotas Google applicables. En mode test, une nouvelle autorisation peut être nécessaire après expiration du jeton. Le JPG est envoyé à l’API de miniature ; les droits de chaîne et les restrictions Shorts peuvent empêcher son application.

Instagram · API officielle

Non connecté

Notice : obtenir les accès Instagram
  1. Passer le compte Instagram en Professionnel (Business ou Creator).
  2. Créer une application dans Meta for Developers et choisir la configuration « Instagram API avec Instagram Login ».
  3. Ajouter votre compte aux rôles/testeurs de l’application et accepter l’invitation depuis Instagram. Pour d’autres utilisateurs, les autorisations et l’examen Meta peuvent être nécessaires.
  4. Autoriser instagram_business_basic et instagram_business_content_publish, puis générer le jeton depuis la configuration Instagram de l’application. Copier ce jeton ici et enregistrer.
  5. « Tester le compte » récupère l’ID professionnel. Pour un jeton court, copier aussi l’Instagram App Secret et utiliser le bouton de passage à 60 jours. Les jetons longue durée suivis par le studio sont renouvelés avant échéance lors des envois, tant qu’ils restent valides.

Utiliser un jeton Instagram Login, pas un jeton Facebook d’un autre parcours. Pas d’abonnement de publication requis ; limites Meta applicables. Les fichiers sont hébergés sur Cloudinary pour fournir les URL publiques de la vidéo et de la couverture JPEG.

TikTok · via Buffer

Non connecté

Notice : obtenir la clé Buffer pour TikTok
  1. Créer un compte Buffer, puis connecter TikTok dans les canaux Buffer. Choisir un compte autorisant la publication automatique.
  2. Créer une clé dans Settings → API, avec les permissions de lecture des comptes/canaux/posts et de création de posts.
  3. Coller la clé, enregistrer, puis récupérer les canaux TikTok et choisir le bon compte. Enregistrer à nouveau.
  4. Configurer la cadence de publication dans Buffer pour le mode « Ajouter à la file ». Une file en pause ne publiera pas tant qu’elle n’est pas réactivée.

Buffer est utilisé uniquement pour TikTok. Les limites et les tarifs dépendent du compte Buffer. L’API ne transmet pas de miniature JPEG personnalisée : le studio peut insérer la miniature générée au début d’une copie de la vidéo et demander ce moment comme couverture. Le fichier original reste intact.

Cloudinary · médias publics pour Instagram et TikTok

Renseignez uniquement les services utilisés : YouTube seul ne nécessite ni Buffer, ni Instagram, ni Cloudinary. TikTok nécessite Buffer et, dans cette version du studio, Cloudinary pour héberger la vidéo. Instagram nécessite ses accès et Cloudinary. La génération locale ne nécessite aucune de ces clés.

Non configuré

Notice : obtenir les accès Cloudinary
  1. Créer un compte sur Cloudinary, puis ouvrir la console.
  2. Dans l’environnement produit et les réglages API Keys, relever le Cloud name, l’API key et l’API secret. Les copier ici, enregistrer, puis tester.
  3. Le studio utilise des envois signés côté serveur et des URL publiques HTTPS stables. Aucun preset non signé n’est nécessaire.

Utile pour Instagram et Buffer TikTok ; YouTube reçoit directement le fichier du poste. Une offre gratuite existe, avec ses quotas. Purge automatique : les médias Cloudinary sont supprimés dès confirmation de publication sur tous les réseaux concernés. Les fichiers du poste sont conservés. Une publication en attente ou en échec bloque la purge.
