# Outils expérimentaux, distincts du studio

Le parcours précédent a utilisé MoneyPrinterTurbo puis ComfyUI et Wan pour essayer des visuels génératifs. Les vidéos éditoriales actuelles sont produites avec des illustrations et animations pilotées par code ; ces outils ne sont donc pas nécessaires au lancement du studio.

- MoneyPrinterTurbo : https://github.com/harry0703/MoneyPrinterTurbo - suivre son README pour l'installation et les éventuels fournisseurs externes. Ses options cloud ne font pas partie du fonctionnement local garanti ici.
- ComfyUI : https://github.com/comfyanonymous/ComfyUI - interface locale pour workflows de diffusion. Installation, dépendances GPU et modèles séparés ; aucun workflow exporté complet de ces anciennes expérimentations n'est fourni dans ce dépôt.
- Wan2.2 : https://github.com/Wan-Video/Wan2.2 - génération vidéo locale, modèles lourds et besoins GPU bien supérieurs au moteur éditorial. Les poids expérimentés Ti2V 5B ne sont pas versionnés.

Ne pas confondre leurs modèles avec les deux chartes graphiques : les chartes sont fournies dans `docs/chartes/` et le moteur portable applique leurs principes. Aucune copie des environnements ni des poids des projets tiers n'est nécessaire pour réutiliser la stack active.
